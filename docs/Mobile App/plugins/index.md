Below is a table generated from dapp.php with this command:

```
dapp actualize plugins list
```

You can find documentation by copy and pasting the plugin ID into a google search to find github repos

Plugins appended with -NECTAR or -actualize are plugins where i manually needed to make changes in the repo to make work, however the documentation should be the same.  But be aware if additional edits are needed to plugins that have been previously modified, that they are being edited from the forked repo.

Want to create your own plugin?? Check out the Cordova Docs: [https://cordova.apache.org/docs/en/latest/guide/hybrid/plugins/index.html](https://cordova.apache.org/docs/en/latest/guide/hybrid/plugins/index.html)
