**What types of events can I create on the platform?**

You can create any event—online or in person—as long as it aligns with our [Community Standards](https://www.actualize.earth/community-standards). Event producers are responsible for ensuring their events comply with local laws, safety regulations, and our platform’s community guidelines.

**How do I create my first event?**

To create an event, you’ll need an active subscription. Once subscribed, go to the Events tab and click the purple ＋ button. Fill out your event details, then click Create! in the top-right corner to publish your event.

**What information do I need to include (title, date, venue, description, etc.)?**

Each event must include a title, a wellbeing category, a locale, a start date and time, a description, and privacy settings. You’re encouraged to fill out as much additional information as possible to help your event stand out and make it easier for attendees to connect.

**Can I duplicate or template past events?**

Yes! Click your event to go to the Event Page, then toggle to Admin Tools at the bottom. Under Event Settings, you may clone your event!

**How do I add co-hosts or collaborators?**

When you are creating an event, there is a host section. Click "+ Hosts" to add co-hosts. You can also add a co-host after creating an event by navigating to Event Settings -> Edit Event and scrolling to the host section.

**How do I create private or invite-only events?**

When creating your event, scroll to the bottom of the form to find the Select Privacy option (set to Public by default). Click it to change your event to Private, so only people with the direct link can view or join it.

**Can I host recurring or multi-day events?**

Yes! There are no restrictions, so you can schedule multiple showtimes or create an event that spans several days.

**How do I upload media (images, videos, promo banners)?**

When creating an event, we allow users to upload a main image for their event page. We have space for descriptions in our event pages where you can add additional images.

**How can I integrate my event with my community profile?**

Your upcoming and previous events will be automatically connected to your profile!

**How do I change my event from Private to Public?**

Go to Edit Event and scroll to the bottom — you'll find the visibility setting there. If you're staging an event before it's ready, it's best practice to create it as Private first, then switch to Public when you're ready to go live.
