## 🌍 Welcome to the Actualize Earth Developer Documentation

“Technology in right relationship to Life.”

Welcome to the Actualize Earth developer ecosystem — a living architecture designed to serve the evolution of consciousness and community through beautiful, resilient, and sovereign systems. This documentation is your guide into the technical and philosophical foundations of how Actualize Earth works: from the lightweight Phi framework and modular front-end system, to the scalable cloud infrastructure and mobile app build process that ties it all together.

Our goal is not just to build software — but to cultivate a regenerative network of people and tools that help individuals and communities self-actualize. As you explore, you’ll see how each layer of the system (front end, back end, mobile app, infrastructure) has been designed with intention: interoperability, security, modularity, and ease of contribution.

## 🪄 Front End

The Front End section guides you through creating and publishing code that lives in the user experience layer of Actualize Earth. Here you’ll learn how to load and extend the Phi framework, use widgets to dynamically render content, and understand the modular structure that keeps the system fast and maintainable. These tools make it possible to create responsive, interactive, and meaningful interfaces that connect users to the broader ecosystem.

[Getting Started](doc:getting-started-2)

## ⚙️ Back End

The Back End powers the intelligence and automation of the platform. This section introduces the common tools and utilities within phi.php, covers CRUD operations, notification systems, image processing, and job scheduling — including how to manage longer-running processes via cron and PM2. It’s designed for efficiency, scalability, and clarity — letting developers focus on logic rather than boilerplate.

[Introduction](doc:introduction-1)

## 📱 Mobile App

The Mobile App section brings the Actualize experience to people’s hands. Here you’ll learn how to install dependencies, manage Cordova plugins, and use the CLI App Builder to assemble, package, and deploy apps. This layer bridges the web and the physical world — allowing Actualize Earth to move beyond browsers into lived experience through portable, event-driven tools.

[Introduction](doc:introduction)

## ☁️ Infrastructure

The Infrastructure section reveals the architecture that makes the entire system hum — from cloud to edge. It walks through the high-availability AWS setup, load balancing, process management, distributed data design, and how the same framework can run on personal nodes for user-owned sovereignty. Together, these components form a blueprint for resilient, ethical, and evolvable digital infrastructure.

[Introduction](doc:introduction-3)

Every part of this documentation exists to help you contribute effectively — not just to code, but to a larger mission: engineering technology that restores dignity, amplifies wellbeing, and supports collective actualization. 🌱
