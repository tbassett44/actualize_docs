Within a view, you can use `this.defaultBottomHeight` to set the default nav height within a view, and `this.setMenuBottom()` to programmatically set the bottom height

```
this.defaultBottomHeight = 40 ; //40px bottom spacing
this.setMenuBottom(80); //set bottom spacing to 80px
```
